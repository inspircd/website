InspIRCd v4.12.1 is now available, [download it from the releases page](https://github.com/inspircd/inspircd/releases/tag/v4.12.1).

The most notable changes in this release are:

* Applied a patch to a vendored library to fix building on 32-bit x86 systems.

* Fixed an issue with the v3 protocol compatibility layer where big channels with parameter modes set would not be synchronised correctly.

* Fixed the httpd module rejecting HTTP requests that are split across multiple TCP packets.

<!--more-->

No breaking configuration changes have been made since the v4.0.0 release. Please consult [the list of breaking changes](https://docs.inspircd.org/4/breaking-changes) if you are upgrading from v3.

The full change log can be found [on the docs site](https://docs.inspircd.org/4/change-log#inspircd-4121) or [on GitHub](https://github.com/inspircd/inspircd/compare/v4.11.0...v4.12.1).
