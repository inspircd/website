InspIRCd v4.12.0 is now available, [download it from the releases page](https://github.com/inspircd/inspircd/releases/tag/v4.12.0).

The most notable changes in this release are:

* Changed extended ban `R:` (account) to also match against account identifiers.

* Fixed build errors on OpenSSL 4.

* Fixed erroneously rejecting TLS groups without a nid in ssl_openssl.

* Fixed flushing WebSocket frames when using native pings.

* Reworked the terminal output on startup to be more helpful.

<!--more-->

No breaking configuration changes have been made since the v4.0.0 release. Please consult [the list of breaking changes](https://docs.inspircd.org/4/breaking-changes) if you are upgrading from v3.

The full change log can be found [on the docs site](https://docs.inspircd.org/4/change-log#inspircd-4100) or [on GitHub](https://github.com/inspircd/inspircd/compare/v4.11.0...v4.12.0).
